# 星海笃行 · Dushi Starfarer

清华大学笃实书院64班特色小游戏。核心玩法参考经典纵向弹幕射击：选择战机穿越星海，躲避弹幕，收集航空航天、软件学院、工业工程系三系徽章，强化飞船。既可在主线中击败三阶段 Boss「混沌核心」并穿越跃迁门抵达终点，也可进入无尽模式不断下潜、冲击最深航迹。

纯前端、零依赖，使用 Canvas 2D 与 Web Audio 实时合成音效；标题/结算、战斗与 Boss 分别使用三首 MP3 BGM。提供 4 种可选战机、7 类敌机与两种游戏模式。三档难度共用同一套机体、敌机与 Boss 数值，只改变弹幕编排；敌弹按航空航天、软件学院、工业工程系三系协议设计，并加入东方 Project 风格的等差弹速与符卡宣言。标题页中央使用笃实书院64班班徽，并做了透明边缘、暗角与轨道环融合处理。

## 立即游玩

- **推荐分享版**：双击 `星海笃行64班.html`，所有 CSS、JS 与三首 MP3 已内联，单文件即可运行。
- **源代码版**：双击 `index.html`；或在本目录执行：

```bash
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

> 声音需要首次点击/触摸后才会启动，这是浏览器的自动播放限制；标题、战斗、Boss 与结算都会自动切换对应 BGM。

## 分享与部署

**最简单：** 把 `星海笃行64班.html` 直接发给对方，对方双击或拖进浏览器即可。该文件约 12.2 MB，班徽与三首 MP3 已内联，不需要服务器。

**转发标题：** 页面 `<title>`、`og:title`、`twitter:title`、iOS 主屏名称与分享文件名均包含「64班」，链接预览会显示为「星海笃行 · 笃实书院64班」。

**静态网站：** 将以下文件上传到任意静态托管（GitHub Pages、Netlify Drop、Vercel、Cloudflare Pages 等）：


脉冲的自然充能、擦弹充能与击毁充能已整体下调约 30%；三系徽章与无尽层奖励的脉冲数值保持不变。

在标题页点击当前战机卡片或「更换」打开战机库。四架战机拥有独立外观、弹道、结构、护盾与射速，选择会保存在本地。

| 战机 | 定位 | 结构 | 护盾 | 特性 |
| --- | --- | ---: | ---: | --- |
| 笃实号 | 均衡 | 3 | 3 | 标准火力与护盾，适合第一次出航 |
| 星火号 | 突击 | 3 | 2 | 高射速、更小判定点，单发伤害较低 |

| 无人机 | 航空航天 | 同轴等差弹速点射：轻松 1 发 / 标准 3 发 / 困难 5 发 |
| 编织者 | 航空航天 | 镜像编织弹流，逐层展开 1 / 2 / 3 层 |
| 穿刺者 | 航空航天 | 高速斜向俯冲后射出等差点射，1 / 3 / 5 发，金色机体 |
| 棱镜哨兵 | 软件学院 | 青紫相间的 2 / 4 / 6 条旋转棱镜臂，紫色机体 |
| 蜂巢母舰 | 软件学院 | 持续放出无人机，并释放带两处缺口的慢速气泡环 |
| 炮台 | 工业工程系 | 驻守上方，旋转齿轮环，齿数 10 / 18 / 26 |
| 观测者 | 三系协议 | 精英单位，依次复现航天等差弹速、软件旋臂与工业齿轮，击毁后掉落徽章 |

## 三系成长

| 徽章 | 强化 | 主要效果 |
| --- | --- | --- |
| 航空航天 | 火力系统 | 提升弹道数量与覆盖范围，最高 5 级 |
| 软件学院 | 算法护盾 | 增加护盾、伴飞单元；护盾可抵挡一次伤害，伴飞单元自动索敌 |
| 工业工程系 | 机动效率 | 提升移动速度、缩短射击间隔，并补充脉冲能量 |

每拾取一枚徽章，都会在画面左上角出现一张**不中断战斗**的短知识卡；卡片自动消失。知识内容覆盖三系的基础概念，可在 `game.js` 的 `KNOWLEDGE` 中替换。

## 难度

三档难度使用完全相同的己方结构、敌人数量、敌机血量、Boss 血量与敌弹基准速度，只改变弹幕密度和编排。

| 难度 | 共用数值 | 弹幕编排 | 得分系数 |
| --- | --- | --- | ---: |
| 轻松 · 观星者 | 3 结构；敌机 / Boss 血量、数量、弹速同标准 | 单发点射、1 层编织、2 条旋臂、更宽的安全缺口 | ×0.9 |
| 标准 · 领航员 | 同上 | 等差三连、2 层编织、3 条旋臂、标准缺口 | ×1.00 |
| 困难 · 破界者 | 同上 | 等差五连、3 层编织、4 条旋臂、更窄的缺口 | ×1.25 |

三档难度分别记录本地最高分。主线通关时间约 3–5 分钟，无尽模式不设终点。

## 弹幕设计：三系协议与符卡

核心语言是东方 Project 常见的**等差弹速**：在同一条瞄准线上同时射出多颗速度呈等差数列的子弹，后发先至、层层收束，形成一条可读、可钻的弹道。难度只改变同一节奏里的发数，不改变基础速度。以无人机为例：

- 轻松：1 发，速度 154。
- 标准：3 发，速度 122 / 154 / 186。
- 困难：5 发，速度 90 / 122 / 154 / 186 / 218。

三种弹幕风格分别对应笃实书院的三系方向：

| 方向 | 视觉与弹型 | 代表敌机 / 符卡 |
| --- | --- | --- |
| 航空航天 | 米弹、四角星弹的等差速度与精准点射 | 无人机、编织者、穿刺者；航天符「逃逸速度」 |
| 软件学院 | 青紫相间的旋转棱镜臂、气泡环与防火墙 | 棱镜哨兵、蜂巢母舰；软件符「三次握手」 |
| 工业工程系 | 带缺口的齿轮环、方弹与节拍式轮转 | 炮台、观测者；工业符「流水线节拍」 |

Boss 的三个阶段不再是单纯的数值强化，而是三张具名符卡：航天符「逃逸速度」、软件符「三次握手」、工业符「流水线节拍」。符卡宣言会显示在战斗画面中，同时 Boss 血条会显示当前符卡名。

敌弹共有五种外观：`rice` 米弹、`orb` 光玉、`bubble` 慢速大玉、`star` 四角星弹与 `square` 方弹；颜色取自三系配色，白芯保证高密度弹幕下仍然可读。

## 模式

| 模式 | 规则 |
| --- | --- |
| 主线远征 | 约 100 秒常规航段后接入三阶段 Boss；击败后开启跃迁门，穿越即通关。 |
| 无尽深空 | 首轮 65 秒后接入 Boss，之后每 70 秒再次接入；每击退一次进入下一层，敌人血量、密度与弹速逐层提升。 |

无尽模式中，每次击退核心会恢复 1 点结构、1 层护盾并补充脉冲，同时掉落三系徽章；没有终点，直到结构归零。最高分与最深层数按「模式 × 难度」独立保存在本地。

## Boss 弹幕难度

Boss 的弹速、发射间隔与血量在三档难度下完全一致，只调整弹量、螺旋臂与安全缺口。

| 难度 | 环形星弹 | 等差瞄准 | 螺旋臂 | 防火墙缺口 | 齿轮齿数 | 齿轮缺口 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 轻松 | 10 | 1 发 | 2 条 | 4 处 | 14 | 4 处、更宽 |
| 标准 | 18 | 3 发 | 3 条 | 3 处 | 22 | 3 处 |
| 困难 | 26 | 5 发 | 4 条 | 2 处 | 30 | 2 处、更窄 |

轻松难度减少环形弹、螺旋臂与瞄准弹数量，并扩大安全区；困难增加弹量、螺旋臂与齿轮齿数，同时收窄缺口，但不会改变敌弹飞行速度。

- 玩家首次触摸/点击页面后启动标题 BGM；开始游戏切到普通战斗 BGM，Boss 战切到 Boss BGM，结算页切回标题 BGM。

## 本局知识档案

每局结束（通关、失败或无尽结算）后，结算页会在航行纪念/成绩之后生成「本局知识档案」：

- 自动汇总本局拾取三系徽章时出现过的知识卡。
- 按航空航天、软件学院、工业工程系分组，并去重。
- 展示学科、知识标题与完整说明；没有拾取知识碎片时会显示提示。
- 知识档案位于结算按钮之前，结算面板可滚动查看全部卡片。

## 主线流程

1. 外环星域：熟悉移动、自动开火与徽章收集。
2. 碎片带：炮台、编织者与观测者精英加入。
3. 混沌边界：约 100 秒后接入 Boss「混沌核心」。
4. Boss 三阶段符卡：航天符「逃逸速度」（星弹环 + 等差弹速）→ 软件符「三次握手」（旋臂 / 防火墙）→ 工业符「流水线节拍」（齿轮缺口 / 节拍弹幕）。
5. 击败 Boss 后，跃迁门在画面上方开启；向上穿越跃迁门即可通关并生成航行纪念卡。

## 无尽流程

1. 深空第 1 层开始，常规波次与精英照常生成。
2. 65 秒后第一次接入混沌核心；击退后进入第 2 层，并获得补给。
3. 每层 Boss 血量约提升 24%，小怪血量约提升 12%，弹速最高提升 20%。
4. 每 70 秒再次接入核心；层数越深，得分与压力同步增长。
5. 结构归零后结算，记录本局得分、抵达层数与历史最深层数。

## 定制

- **班级名称**：修改 `game.js` 顶部的 `CLASS_NAME` 常量，例如：

```js
const CLASS_NAME = '笃实书院 · 64班';
```

所有 `data-class-name` 文本与通关纪念卡署名会同步更新。

- **知识卡内容**：修改 `game.js` 中的 `KNOWLEDGE`，每个条目为 `{ title, text }`。
- **己方战机**：修改 `SHIPS` 中的结构、护盾、射速、伤害、判定点与配色；弹道在 `SHIP_PATTERNS` 中。
- **敌机种类**：`spawnEnemy()` 定义基础属性，`updateEnemies()` 与 `drawEnemies()` 分别控制行为与外观；波次组合在 `spawnWave()`。
- **难度参数**：修改 `DIFFICULTIES` 中的 `tier`（0 / 1 / 2）、`shotNote` 与 `scoreMul`。三档难度共用同一套结构、敌人血量、Boss 血量、刷怪节奏与敌弹速度。
- **敌机弹幕**：`updateEnemies()` 中每种敌机的 `[1, 3, 5][tier]` 一类数组控制三档发数；`ladderShot()` 生成等差弹速，`weaveShot()`、`spiralVolley()` 与 `radialGaps()` 分别生成编织弹流、旋臂与齿轮缺口。
- **小怪血量**：修改 `spawnEnemy()` 中无人机、编织者、炮台、穿刺者、哨兵、母舰与精英的 `hp` 基准值；基准值对三档难度一致。
- **主色与视觉**：修改 `styles.css` 顶部的 `:root` 变量（清华紫、青色、金色等）。
- **Boss 血量**：`createBoss()` 中的 `1420 * layerScale`；无尽模式再乘以层数系数，与难度无关。
- **主线长度**：`updateSpawner()` 中的 `game.time >= 100` 控制 Boss 出场时间。
- **无尽节奏**：`resetRun()` 的 `nextBossAt = 65` 与 `resumeEndless()` 的 `game.nextBossAt = game.time + 70`。
- **BGM**：三首 MP3 位于 `assets/audio/menu.mp3`、`normal.mp3` 与 `boss.mp3`；曲名、艺术家与音量在 `game.js` 的 `BGM_TRACKS` 中调整。重新构建单文件版时会自动把三首 MP3 内联。
- **Boss 弹幕**：修改 `BOSS_TUNING` 中三档难度的环形弹数、等差瞄准发数、螺旋臂、防火墙缺口与齿轮齿数 / 缺口宽度；弹速与发射间隔三档一致。
- **符卡名称**：修改 `SPELL_CARDS`，Boss 阶段标题与符卡宣言会同步更新。
- **单文件版 / 网页包**：改完源码后运行：

```bash
python tools/build_standalone.py
python tools/build_web_zip.py
```

## 技术说明

- 单 Canvas 2D 渲染，DPR 上限 2；星野、弹幕、战机、敌机、Boss 与粒子均为程序化绘制，无外部图片。
- Web Audio 实时合成射击、拾取、爆炸、脉冲与警告音；BGM 使用三首内联/外置 MP3，在标题、战斗、Boss 与结算间淡入淡出。
- 四架战机拥有独立弹道、数值与矢量外观；七类敌机拥有独立移动、开火与绘制逻辑。
- 移动端采用相对拖动，手指不会遮挡飞船；触控与键盘可以混用。
- 自适应 320–760 px 宽度，适配刘海屏安全区与竖屏手机。
- 分数、无尽最深层数与当前战机保存在 `localStorage`；不依赖后端、不发起游戏数据请求。
- 调试入口：仅在 URL 带 `?debug=1` 时暴露 `window.__DUSHI_DEBUG__`，用于测试 Boss 阶段、无尽层数、快速充能和结果页。
