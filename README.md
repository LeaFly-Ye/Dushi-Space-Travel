# 星海笃行 · Dushi Starfarer

清华大学笃实书院特色小游戏。核心玩法参考经典纵向弹幕射击：选择战机穿越星海，躲避弹幕，收集航空航天、软件学院、工业工程系三系徽章，强化飞船。既可在主线中击败三阶段 Boss「混沌核心」并穿越跃迁门抵达终点，也可进入无尽模式不断下潜、冲击最深航迹。

纯前端、零依赖，使用 Canvas 2D 与 Web Audio 实时合成音效；标题/结算、战斗与 Boss 分别使用三首 MP3 BGM。提供 4 种可选战机、7 类敌机与两种游戏模式。

## 立即游玩

- **推荐分享版**：双击 `星海笃行.html`，所有 CSS、JS 与三首 MP3 已内联，单文件即可运行。
- **源代码版**：双击 `index.html`；或在本目录执行：

```bash
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

> 声音需要首次点击/触摸后才会启动，这是浏览器的自动播放限制；标题、战斗、Boss 与结算都会自动切换对应 BGM。

## 分享与部署

**最简单：** 把 `星海笃行.html` 直接发给对方，对方双击或拖进浏览器即可。该文件约 11.5 MB，三首 MP3 已内联，不需要服务器。

**静态网站：** 将以下文件上传到任意静态托管（GitHub Pages、Netlify Drop、Vercel、Cloudflare Pages 等）：

```text
index.html
styles.css
game.js
assets/audio/menu.mp3
assets/audio/normal.mp3
assets/audio/boss.mp3
```

也可以直接上传 `星海笃行-网页版.zip` 解压后的内容。入口为 `index.html`，无需 Node 或后端。

**手机同 Wi-Fi 试玩：**

```bash
python -m http.server 8000 --bind 0.0.0.0
```

电脑与手机连接同一网络，手机浏览器访问 `http://电脑局域网IP:8000/`。游戏已适配 320px 以上宽度、触摸拖动、刘海安全区与 iOS 音频解锁流程。

## 操作

| 操作 | 方式 |
| --- | --- |
| 移动 | 按住画面任意位置拖动（相对操控）；桌面也支持 WASD / 方向键 |
| 射击 | 自动开火 |
| 笃实脉冲 | `SPACE` / 右下角按钮（充能满后清屏并重创敌人） |
| 暂停 | `ESC` / `P` / 右上角暂停按钮 |
| 静音 | `M` / 右上角声音按钮 |

飞船中央的白色小点是真实判定点，机体边缘不会碰撞。贴近敌弹会触发「擦弹」，增加少量分数与脉冲充能。

## 己方战机

在标题页点击当前战机卡片或「更换」打开战机库。四架战机拥有独立外观、弹道、结构、护盾与射速，选择会保存在本地。

| 战机 | 定位 | 结构 | 护盾 | 特性 |
| --- | --- | ---: | ---: | --- |
| 笃实号 | 均衡 | 难度基础值 | 3 | 标准火力与护盾，适合第一次出航 |
| 星火号 | 突击 | 难度基础值 | 2 | 高射速、更小判定点，单发伤害较低 |
| 长城号 | 重装 | +1 | 2 | 宽弹道、重火力、额外结构，判定点更大 |
| 天问号 | 技术 | 难度基础值 | 4 | 开局 1 层护盾，额外伴飞单元 |

## 敌机类型

| 敌机 | 行为 |
| --- | --- |
| 无人机 | 基础编队单位，瞄准单发 |
| 编织者 | 横向游走，三向扇形弹 |
| 炮台 | 驻守上方，旋转环形弹 |
| 穿刺者 | 高速斜向俯冲，双发瞄准弹，金色机体 |
| 棱镜哨兵 | 会短距折跃换位，四向旋转弹幕，紫色机体 |
| 蜂巢母舰 | 缓慢推进并持续放出无人机，击毁后掉落徽章 |
| 观测者 | 精英单位，环形弹与扇形弹交替，击毁后掉落徽章 |

## 三系成长

| 徽章 | 强化 | 主要效果 |
| --- | --- | --- |
| 航空航天 | 火力系统 | 提升弹道数量与覆盖范围，最高 5 级 |
| 软件学院 | 算法护盾 | 增加护盾、伴飞单元；护盾可抵挡一次伤害，伴飞单元自动索敌 |
| 工业工程系 | 机动效率 | 提升移动速度、缩短射击间隔，并补充脉冲能量 |

每拾取一枚徽章，都会在画面左上角出现一张**不中断战斗**的短知识卡；卡片自动消失。知识内容覆盖三系的基础概念，可在 `game.js` 的 `KNOWLEDGE` 中替换。

## 难度

| 难度 | 结构 | 弹幕与敌人 |
| --- | --- | --- |
| 轻松 · 观星者 | 4 | 弹速较慢、敌人密度较低、Boss 血量较低 |
| 标准 · 领航员 | 3 | 均衡 |
| 困难 · 破界者 | 2 | 弹速更快、敌人更密、Boss 血量更高，得分系数 1.25 |

三档难度分别记录本地最高分。主线通关时间约 3–5 分钟，无尽模式不设终点。

## 模式

| 模式 | 规则 |
| --- | --- |
| 主线远征 | 约 100 秒常规航段后接入三阶段 Boss；击败后开启跃迁门，穿越即通关。 |
| 无尽深空 | 首轮 65 秒后接入 Boss，之后每 70 秒再次接入；每击退一次进入下一层，敌人血量、密度与弹速逐层提升。 |

无尽模式中，每次击退核心会恢复 1 点结构、1 层护盾并补充脉冲，同时掉落三系徽章；没有终点，直到结构归零。最高分与最深层数按「模式 × 难度」独立保存在本地。

## Boss 弹幕难度

| 难度 | 弹幕规模 | 弹速 | 发射间隔 | 安全缺口 |
| --- | --- | --- | --- | --- |
| 轻松 | ×0.72 | ×0.86 | ×1.25（更慢） | 更多、更宽 |
| 标准 | ×1.00 | ×1.00 | ×1.00 | 当前基准 |
| 困难 | ×1.28 | ×1.10 | ×0.82（更快） | 更少、更窄 |

标准难度保持此前的 Boss 弹幕强度不变；轻松减少环形弹、螺旋臂与瞄准弹数量，并扩大安全区；困难增加弹量、螺旋臂与弹速，同时收窄缺口。

## BGM 与音效

游戏使用三首 MP3 BGM，并在标题、战斗、Boss 与结算之间自动淡入淡出切换：

| 场景 | 曲名 | 文件位置 |
| --- | --- | --- |
| 标题画面 / 结算画面 | MiracleMirinaeMirage - 宇宙巫女帰還する | `assets/audio/menu.mp3` |
| 常规波次 / 小怪战 | MiracleMirinaeMirage - 遥か３８万キロのボヤージュ | `assets/audio/normal.mp3` |
| Boss 战 | MiracleMirinaeMirage - パンデモニックプラネット | `assets/audio/boss.mp3` |

三首 MP3 直接随项目提供。原程序化 BGM 已移除，只保留射击、拾取、爆炸、护盾、脉冲、Boss 警告与结算音效的 Web Audio 实时合成。

- 玩家首次触摸/点击页面后启动标题 BGM；开始游戏切到普通战斗 BGM，Boss 战切到 Boss BGM，结算页切回标题 BGM。
- BGM 音量已调高，射击与拾取音效保持不变。
- 右上角声音按钮或 `M` 键静音；暂停时 BGM 自动压低。
- `星海笃行.html` 单文件版会把三首 MP3 以 Base64 内联，分享时只需发送 HTML；源码版 `index.html` 使用 `assets/audio/` 目录。
- 小怪血量已下调：无人机 4→2.6、编织者 11→7、炮台 26→15、精英观测者 115→85（基准值，仍受难度与无尽层数缩放）。

## 本局知识档案

每局结束（通关、失败或无尽结算）后，结算页会在航行纪念/成绩之后生成「本局知识档案」：

- 自动汇总本局拾取三系徽章时出现过的知识卡。
- 按航空航天、软件学院、工业工程系分组，并去重。
- 展示学科、知识标题与完整说明；没有拾取知识碎片时会显示提示。
- 知识档案位于结算按钮之前，结算面板可滚动查看全部卡片。

## 主线流程

1. 外环星域：熟悉移动、自动开火与徽章收集。
2. 碎片带：炮台、编织者与观测者精英加入。
3. 混沌边界：约 100 秒后接入 Boss「混沌核心」。
4. Boss 三阶段：航天协议（环形弹幕）→ 软件协议（螺旋弹流/防火墙）→ 工业协议（齿轮缺口/节拍弹幕）。
5. 击败 Boss 后，跃迁门在画面上方开启；向上穿越跃迁门即可通关并生成航行纪念卡。

## 无尽流程

1. 深空第 1 层开始，常规波次与精英照常生成。
2. 65 秒后第一次接入混沌核心；击退后进入第 2 层，并获得补给。
3. 每层 Boss 血量约提升 24%，小怪血量约提升 12%，弹速最高提升 20%。
4. 每 70 秒再次接入核心；层数越深，得分与压力同步增长。
5. 结构归零后结算，记录本局得分、抵达层数与历史最深层数。

## 定制

- **班级名称**：修改 `game.js` 顶部的 `CLASS_NAME` 常量，例如：

```js
const CLASS_NAME = '笃实书院 · 航21班';
```

所有 `data-class-name` 文本与通关纪念卡署名会同步更新。

- **知识卡内容**：修改 `game.js` 中的 `KNOWLEDGE`，每个条目为 `{ title, text }`。
- **己方战机**：修改 `SHIPS` 中的结构、护盾、射速、伤害、判定点与配色；弹道在 `SHIP_PATTERNS` 中。
- **敌机种类**：`spawnEnemy()` 定义基础属性，`updateEnemies()` 与 `drawEnemies()` 分别控制行为与外观；波次组合在 `spawnWave()`。
- **难度参数**：修改 `DIFFICULTIES`，包括生命、敌弹速度、敌人密度、Boss 血量与得分倍率。
- **小怪血量**：修改 `spawnEnemy()` 中无人机、编织者、炮台、穿刺者、哨兵、母舰与精英的 `hp` 基准值。
- **主色与视觉**：修改 `styles.css` 顶部的 `:root` 变量（清华紫、青色、金色等）。
- **Boss 血量**：`createBoss()` 中的 `1420 * d.bossHp`；无尽模式再乘以层数系数。
- **主线长度**：`updateSpawner()` 中的 `game.time >= 100` 控制 Boss 出场时间。
- **无尽节奏**：`resetRun()` 的 `nextBossAt = 65` 与 `resumeEndless()` 的 `game.nextBossAt = game.time + 70`。
- **BGM**：三首 MP3 位于 `assets/audio/menu.mp3`、`normal.mp3` 与 `boss.mp3`；曲名、艺术家与音量在 `game.js` 的 `BGM_TRACKS` 中调整。重新构建单文件版时会自动把三首 MP3 内联。
- **Boss 弹幕**：修改 `BOSS_TUNING` 中三档难度的弹量、弹速、间隔、螺旋臂与安全缺口。
- **单文件版 / 网页包**：改完源码后运行：

```bash
python tools/build_standalone.py
python tools/build_web_zip.py
```

## 技术说明

- 单 Canvas 2D 渲染，DPR 上限 2；星野、弹幕、战机、敌机、Boss 与粒子均为程序化绘制，无外部图片。
- Web Audio 实时合成射击、拾取、爆炸、脉冲与警告音；BGM 使用三首内联/外置 MP3，在标题、战斗、Boss 与结算间淡入淡出。
- 四架战机拥有独立弹道、数值与矢量外观；七类敌机拥有独立移动、开火与绘制逻辑。
- 移动端采用相对拖动，手指不会遮挡飞船；触控与键盘可以混用。
- 自适应 320–760 px 宽度，适配刘海屏安全区与竖屏手机。
- 分数、无尽最深层数与当前战机保存在 `localStorage`；不依赖后端、不发起游戏数据请求。
- 调试入口：仅在 URL 带 `?debug=1` 时暴露 `window.__DUSHI_DEBUG__`，用于测试 Boss 阶段、无尽层数、快速充能和结果页。
